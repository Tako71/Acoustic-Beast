# Acoustic Beast

Веб-приложение для анализа уровней шума на производственных объектах.  
Разработано в рамках выпускной квалификационной работы (ВКР) магистратуры СПбГТИ(ТУ).

**Автор:** Пилецки Артем

---

## О проекте

Acoustic Beast автоматизирует расчёт эквивалентного уровня шума на рабочих местах в соответствии с **ГОСТ ISO 9612-2016** и оценку соответствия нормативным требованиям **СанПиН 2.2.4.3359-16**.

Приложение позволяет:
- Проводить расчёт по трём стратегиям ГОСТ ISO 9612-2016
- Выявлять превышения предельно допустимого уровня (ПДУ = 80 дБ)
- Формировать рекомендации по снижению шума
- Выгружать отчёт в формате PDF
- Сохранять историю всех расчётов

---

## Стратегии расчёта

| Стратегия | Описание |
|-----------|----------|
| По рабочим операциям | Расчёт на основе уровней шума и длительности каждой операции |
| По трудовой функции | Расчёт на основе измерений в течение функциональных периодов |
| По рабочему дню | Расчёт на основе случайной выборки измерений за смену |

## Технологии

- **Backend:** Python 3.11, Django 4.2
- **База данных:** PostgreSQL
- **Frontend:** Bootstrap 5, Chart.js, AOS
- **PDF:** ReportLab
- **Деплой:** Docker, Gunicorn, Whitenoise

---

## Запуск через Docker (рекомендуется)

```bash
# Клонировать репозиторий
git clone git@github.com:Tako71/Acoustic-Beast.git
cd Acoustic-Beast

# Запустить приложение и БД
docker compose up --build -d

# Создать администратора
docker compose exec web python manage.py createsuperuser
```

Приложение будет доступно по адресу: **http://localhost:8000**

---

## Локальный запуск (для разработки)

**Требования:** Python 3.11+, PostgreSQL

```bash
# Создать виртуальное окружение
python -m venv .venv
source .venv/bin/activate

# Установить зависимости
pip install -r requirements.txt

# Настроить переменные окружения
cp .env.example .env  # отредактировать под свои настройки

# Применить миграции
python manage.py migrate

# Запустить сервер
python manage.py runserver
```

## Нормативная база

- **ГОСТ ISO 9612-2016** — Акустика. Измерения шума для оценки его воздействия на человека. Метод измерений на рабочих местах
- **СанПиН 2.2.4.3359-16** — Санитарно-эпидемиологические требования к физическим факторам на рабочих местах
